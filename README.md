# PulseVision Live Rep Counter

PulseVision Live Rep Counter is a vision-based fitness tracker that uses AI-assisted detection to identify exercises, count reps, and support real-time workout feedback.

## Stack

- React
- TypeScript
- Vite
- Recharts
- Gemini API integration

## Features

- Camera-enabled workout tracking
- AI-assisted rep counting
- Real-time exercise and form feedback workflows
- Fitness dashboard and summary views

## Development

Prerequisites:

- Node.js

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
